# LS Plumbing & Heating Limited

Prospect website prototype for LS Plumbing & Heating — Leeds heating and plumbing specialists (Est. 2005).

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:5175](http://localhost:5175).

## Production build

```bash
npm run build
npm run preview
```
